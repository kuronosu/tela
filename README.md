# Tela

A desktop UI framework in **pure Go**: no cgo, no webview, no native toolkits.
CSS-level layout and styling (Tailwind vocabulary), a React/JSX-like API, and
designed so both people and LLM agents can build beautiful interfaces.

Targets: Linux (Wayland/X11), Windows, macOS.
