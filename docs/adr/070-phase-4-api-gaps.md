# ADR-070: Phase-4 API gaps

- **Date:** 2026-10-13
- **Status:** Accepted

## Decision

Phase-4 API gaps (phase 5, T9; the API is the owner's decision). `ElementRef.Bounds() tela.Rect` is the element's border box in window coordinates as painted: moved by the scroll offsets of its containers and by its own and its ancestors' transforms, as the axis-aligned box of the transformed box (`getBoundingClientRect`; an inline element has the union of its fragments); zero before mount, when `display: none` or before layout. `tela.Rect` is new, `{X, Y, Width, Height float32}` with `Right`, `Bottom`, `Contains` (an alias of `core.Rect`; `gfx.Rect` keeps its corners). `tela.UseBounds(ref) *Value[Rect]` is updated by the Tree at the end of every frame that ran the pipeline (outside `Frame`, like `UseScroll`'s values) when the bounds changed, so its readers (a build, a `WidthFn`) run in the next frame, one frame after the change, and a frame that moves nothing requests none; because one frame is not enough for a one-shot render, `core.Render` and the headless entry points of `telatest` (so `tela snapshot` and `inspect`) run frames until the tree has no work, at most 8 (state set by layout effects and by passive effects of the first frame is now rendered too). `h.If[C tela.Child](cond, c C) C` returns `c` or the zero value, so it takes nodes and props (the zero `Prop` is a no-op, also in `Fragment` and `Provider`, which used to panic on it); `h.IfElse`; `h.MapIndex(items, func(i, item) Node)`. `Value.Latest()` is the applied value with every pending `Set` and `Update` applied in queue order: each Value keeps its pending operations, appended under a lock together with the update so both orders agree; `Update` functions run again on the caller's goroutine (they must be pure and must not call `Latest` of their own Value); it never subscribes and is safe from any goroutine; `Get` is unchanged. `h.TextFn(fn)` is a text node whose function is evaluated when the box phase assembles its paragraph, with its reads tracked (`obsText`): a change reassembles that paragraph, which is shaped and laid out only if the text changed; no build, no style. `tela inspect --layout` and `telatest.LayoutJSON` keep `rect` (layout, no scroll, no transform) and add `bounds` (same shape; scroll and transforms applied) only when it differs from `rect` by more than 1/1000 px. CSS border triangles already drew like Chromium's (adjacent sides are cut along the diagonal from the outer to the inner corner, ADR-045); the bug was in unequal widths: the wedge of a side extended past the inner edge and painted over the opposite side, so a side's region is now bounded by its inner edge, moved inwards by the inner corner radius (Blink's quad of a side). `space-x-*` and `space-y-*` are no longer gaps (supersedes the "gap in flex containers" part of ADR-044): `ComputedStyle.SpaceX/SpaceY` are lengths, negative values allowed (`-space-x-2`), that become the inline-end / block-end margin of every child element but the last (`:where(& > :not(:last-child))`, DOM sense: a trailing `display: none` or absolute child still counts) in block and flex containers alike, and independent of `gap-*`; a margin of the child on that side wins (the rule has no specificity; an explicit `mr-0` cannot be told from none); a positive `space-x-*` between the inline elements of a paragraph stays an empty inline box and a negative one is ignored there

## Rationale

Checked against Chromium 152 with Tailwind 4.3.3 pages (`testdata/chromium/borderjoin`, `space`: 7 rows of triangles, pinwheels, rounded and translucent joins, and 9 rows of avatars, block, flex, wrap, justify, own margins, hidden last child, at scales 1 and 2): geometry within 0.01 px, pixels within 63 levels at join seams (mean ≤ 0.23); before the fix a side of a box with widths 6/12/18/3 painted 208 levels off. `UseBounds` costs one comparison per follower per frame; a subscription would need layout-time hooks in `layout`. Margins instead of gaps because only margins reproduce Tailwind v4 in wrapped, `justify-between` and column flex containers
