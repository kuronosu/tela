# ADR-094: `App.Root` is a `Component` and `h.If`/`h.IfElse` return a `Child`

- **Date:** 2026-10-21
- **Status:** Accepted

## Decision

`App.Root` is a `Component` and `h.If`/`h.IfElse` return a `Child` (phase 7, before v0.7.0; both the owner's decisions; amends ADR-070, ADR-088 and ADR-092). **`App.Root`** is a `tela.Component` instead of `func() Node`: `tela.Main(tela.App{Root: Main{}})` for a struct component, `Root: tela.C(Counter)` for a function one (a Node works too); `Run` and `Main` mount `core.NodeOf(app.Root)`, `telatest.MountApp` mounts `app.Root` as is (`Mount(tb, app.Root, FromApp(app), opts...)`) and a package that defines only `App` renders `app.Root` as is in the CLI, so a function root is `tela.C(fn)` everywhere, as in `Preview`; a nil `Root` still panics in `Run`/`Main` and fails `MountApp` and the CLI, with messages that show both forms (`Root: tela.C(Counter)`, `Root: Counter{}`); `FromApp` and the reflection test over `App`'s fields are unchanged (Root stays ignored there). **`h.If` and `h.IfElse`** are `If(cond bool, c tela.Child) tela.Child` and `IfElse(cond bool, a, b tela.Child) tela.Child` instead of generic over `C tela.Child`: `If(loading, Spinner{})` works for struct components, nodes and props. An absent `If` branch is the empty child of its kind: the zero `Prop` or `StyleProp` for a prop (no effect, no child, also in `Fragment`, a Provider, `Presence` and `Portal`) and the zero `Node`, the hole of ADR-044, otherwise (a struct component, a node, a nil Child), which `addChild` and `addGroupChild` already take in every position, so toggling it keeps the siblings' state; `IfElse` returns the chosen branch as is. `core.CheckIf` and the dev panic for struct components of ADR-088 are removed, as are the `tela.Component(X{})` conversions that worked around it (`examples/dashboard`, `examples/signup`). The result is a `Child`, not a `Node`: a function component that returned `If(...)` returns `Fragment(If(...))`, and `[]tela.Prop` or `...Prop` parameters cannot take it, so `tela.C`, `CP` and `Memo` take their optional key as `...tela.Child` (`C(f, If(cond, Key(id)))` keeps working; anything but a `Key` prop, a nil Child or an empty `If` panics as before). `core.If` (nodes, internal) is unchanged.

## Rationale

Both are the owner's: one line per app for `Root` and one call for conditional struct components, instead of a function literal wrapping `Fragment(Main{})` and `If(c, tela.Component(X{}))`; a `Child` is the one type that fits every position, so no dev check is left to maintain. The price is source breaks the compiler flags at every site: `Root: Counter` becomes `Root: tela.C(Counter)` (one line per app), and `return If(...)` from a function returning `tela.Node` becomes `return Fragment(If(...))`. Rendering is unchanged: every golden is bit-identical
