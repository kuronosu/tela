# ADR-131: Engine additions for `kit`

- **Date:** 2026-10-25
- **Status:** Accepted

## Decision

Engine additions for `kit` (phase 10, T2; decided without the owner, from ADR-129's list; amends §10, §16, §17, ADR-058, ADR-087 and ADR-097). **`h.AriaInvalid(bool)`** works like ADR-097's `AriaRequired`: `style.StateAriaInvalid` (in `AriaStates`, so `group-` and `peer-` work and `setAriaStates` restyles narrowly), the `aria-invalid:` variant and `aria-[invalid=true]:`. The node's `semantics.StateInvalid` follows Chromium's accessibility tree (`AXNodeObject::GetInvalidState`): the prop when it is set, true or false, else a text field's own validity (the state of ADR-069's `invalid:`), except a read-only or disabled field, which HTML bars from constraint validation; `semantics.Node.Invalid` holds the prop alone. Playwright 1.61.1's default aria snapshot does print it (ADR-058's port had left it out because Tela had no prop): `toAriaNode` reads `getAriaInvalid`, the attribute only, for the roles application, checkbox, columnheader, combobox, gridcell, listbox, radiogroup, rowheader, searchbox, slider, spinbutton, switch, textbox and tree, and `createKey` writes ` [invalid]` after `[expanded]`; Tela does the same from `Node.Invalid`, so an email field with a bad value is invalid for assistive technologies but prints no `[invalid]`, as in Playwright. A new aria case is checked byte for byte against Playwright 1.61.1 (the other 16 still match). **`h.AriaSort(string)`**: `ascending`, `descending`, `other`, `none` (ASCII case-insensitive; unknown values panic in dev mode with the closest one and are ignored otherwise, ADR-096's tokens); `semantics.Node.Sort` ("" for none); Playwright does not print aria-sort. The arbitrary `aria-[sort=ascending]:` and `aria-[sort=descending]:` (also `group-`, `peer-`) test the new flags `StateAriaSortAscending` and `StateAriaSortDescending`, set from the prop like the others; `other` and `none` have no variant, and the unsupported-class error of every other `aria-[…]:` lists the supported ones. A quoted value (`aria-[sort="ascending"]:`) is accepted, as in a CSS attribute selector. telatest: `Invalid(bool)` (the message says whether `h.AriaInvalid` or the field's validity decided) and `Sort(string)` ("none" matches an unset header), both in `Expect`'s state list. **i18n calendar data.** `FirstDayOfWeek(tag string) time.Weekday` and `Formatter.FirstDayOfWeek()` read CLDR 48 `supplemental.weekData.firstDay` (vendored alone as `cldr/supplemental/weekData.json`): the `-u-fw-` extension when the tag has one, else the region of `-u-rg-`, the tag's own region, or its language's likely one (x/text's `Tag.Region`: en is US, ar EG, ja JP, pt BR), else Monday (CLDR's 001; also for tags that are not BCP 47 and for macro regions such as 419, as in ICU); alternative variants (`GB-alt-variant`) are ignored. `Formatter.MonthName(time.Month, NameWidth)` and `Formatter.WeekdayName(time.Weekday, NameWidth)` with `NameWidth` = `NameWide` (zero), `NameAbbreviated`, `NameShort`, `NameNarrow` (prefixed because `Short` is a `DateStyle`) return CLDR's stand-alone names, which the generator now vendors (months abbreviated, wide, narrow; days abbreviated, wide, short, narrow): a calendar shows a name on its own ("октябрь", where a date says "5 октября"). Months have no short width in CLDR, so `NameShort` is the abbreviated one. The date patterns keep using the format names, so no formatted output changes. Invalid months, weekdays and widths panic. **Cost:** the vendored data grows from 294 KB to 505 KB, `dates_gen.go` from 110 to 168 KB (124 fields per locale instead of 60, plus the 71 regions whose week does not start on Monday, in three strings); a hello-world that imports `i18n` grows by 26 KB (25.68 to 25.70 MB unstripped, 20.32 to 20.35 MB stripped; `i18n` as a whole adds 0.62 MB, 0.45 MB stripped)

## Rationale

kit's form fields style `aria-invalid:` as shadcn does, its table rotates a sort arrow and its calendar needs localized names and the first weekday. Matching Chromium for the state and Playwright for the snapshot keeps both contracts: the platform accessibility backends will expose what a browser exposes, and the YAML stays byte for byte Playwright's. Two flags for the two sort directions keep the variant inside `istate` and the narrow restyle of ADR-097 instead of a value comparison per class; the other values are rarely styled. Stand-alone names are what calendars and pickers use (ICU's `LLLL`, react-day-picker's `cccccc`); exposing the format ones would show genitive months in Slavic languages. Every existing golden is bit-identical
