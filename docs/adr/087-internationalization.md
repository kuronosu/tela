# ADR-087: Internationalization

- **Date:** 2026-10-20
- **Status:** Accepted

## Decision

Internationalization (phase 7, T7a; the owner chose the data source, catalog format and API shape; amends ADR-011 and §5). **Package** `i18n` is public, above `tela`/`h` and below `aria`/`kit` (kit components will format dates and numbers); it imports `tela` and `internal/core` (the `EnvDev` constant) only, so the order line of §5 gains `i18n` after `tela/h`. **Dependency:** `golang.org/x/text` (BSD-3, pure Go; v0.43.0, already an indirect dependency of go-text at v0.21.0): `language` for tags, CLDR parents and matching, `feature/plural` for cardinal and ordinal rules, `number` (through `message.Printer`) for decimal and percent formatting; CLDR 32 data, so languages that gained the `many` category since (es, fr, it, pt for 1,000,000) do not have it. **Catalogs** are JSON, one file per locale named after it (`es.json`, `en-US.json`; underscores accepted), with ICU MessageFormat values, nested objects giving dotted keys; `Load(fsys, pattern)` parses every message (own parser: arguments, `number`/`date`/`time` with the short styles, `plural` with `=N`, keywords and `offset`, `selectordinal`, `select`, nesting, `#`, ICU's double-optional apostrophe mode) and fails as a whole with file, key, line and column; skeletons, patterns, currencies, units, spellout and `choice` are rejected at load time. **State** is a process-wide immutable snapshot swapped atomically (like `tela.Assets` it is a global registry: catalogs, fallback, explicit locale), so `T`, `Locale` and the hooks never lock and `Load`, `SetLocale` and `SetFallback` are safe from any goroutine. `Locale()` and `UseLocale()` return a BCP 47 string, not an x/text type, so apps do not depend on that module; the current locale is the explicit one, else the system's (Windows `GetUserDefaultLocaleName`, else `LC_ALL`/`LC_MESSAGES`/`LANG`, first one set decides, `C`/`POSIX` is none) when a catalog covers its language, else the fallback (`en` when loaded, else the first catalog loaded, or `SetFallback`), so the locale of a catalog-less `SetLocale("fr")` is kept for number, date and list formatting. A message is looked up in the locale's catalog, its CLDR parents' (es-MX, es) and the fallback's (matching: exact tag, `Tag.Parent()` chain, then x/text's matcher when the language is the same or the confidence is high); a message from another language than the locale's (the fallback's) is evaluated with that message's locale, so its plural rules and digits fit its text. A missing key returns the key and, with `TELA_DEV=1`, is reported once per locale and key on stderr (also: odd argument lists, a missing or mistyped argument, which keep their `{name}`). **Arguments** are name/value pairs (`t("files", "count", n)`, the `log/slog` convention; one form, no map). **Components:** `UseLocale`, `UseT` and `UseFormatter` are ordinary hooks built from `UseContext`, `UseState` and `UseEffect`, with no change to `core`: the effect subscribes a callback to the package's subscriber list (cleanup unsubscribes) and the callback calls `Setter.Update(func(string) string { return Locale() })`, which applies on the UI thread reading the locale at that moment, so racing `SetLocale` calls end on the last and an equal locale rebuilds nothing; the effect also catches up once after subscribing (a change between build and effect). Only components that call a hook rebuild; `T` and the `Format…` functions are not hooks and never subscribe (documented). **`i18n.Provider(tag, children...)`** (a context) fixes the locale of a subtree and the hooks below it ignore the global locale: the isolation for tests (telatest mounts under a Provider, no new telatest option) and for previews. **`Formatter`** (`For(tag)`, `UseFormatter()`, zero value = current locale) carries `T`, `Number`, `Date`, `Time`, `DateTime`, `List`, `Locale`, `Dir`; the package-level `T`, `FormatNumber`, `FormatDate`, `FormatTime`, `FormatDateTime`, `FormatList` are the zero Formatter's methods. **Dates and lists:** x/text keeps its date tables private and has no list patterns, so `i18n/internal/gen` (`go generate`) reads CLDR 48 JSON vendored per locale in `i18n/internal/gen/cldr` (only the used subtree of `ca-gregorian.json` and `listPatterns.json`, original paths; Unicode License v3, listed in `THIRD_PARTY.md`; `-fetch` refreshes it) and emits `dates_gen.go`: a string pool plus one fixed record per locale (month and weekday names, AM/PM, eras, the four date and time patterns, date-time glue with CLDR's `atTime` form for full and long, the standard list patterns) for 113 locales: 88 languages and 25 regional variants whose patterns differ; other locales resolve by the same parent/matcher rule (en-SG to en-001, es-PE to es-419, zh-TW to zh-Hant), unknown ones use English. The formatter interprets LDML patterns (`G y M L d E c e a b B h H K k m s z v`; the generator fails on any other letter in a standard pattern), Gregorian calendar only (Thai prints CE years with the era), in the `time.Time`'s own zone (zone names are abbreviations or `GMT+1`, not localized), digits in the locale's own numbering system (found by formatting 0 to 9 with x/text, so dates and numbers agree). `DateStyle` is `Short < Medium < Long < Full`. **Direction:** `Dir(tag)` is `RTL` when the tag's script (own or the language's default, `Tag.Script`) is Arabic, Hebrew, Thaana, Syriac, N'Ko, Adlam and a few others; layout mirroring and `rtl:` are phase 7 T7b. **Cost:** importing `i18n` adds about 0.7 MB to an unstripped hello-world Tela binary (23.9 to 24.6 MB; 0.5 MB stripped), most of it x/text's plural and number tables and about 0.1 MB the generated dates

## Rationale

Owner's decisions (x/text, JSON with ICU, the API names); the rest follows the precedents: a global registry like `tela.Assets`, environment hooks like `UseColorScheme` (here from public hooks only, so two other agents could change `core` and `telatest` meanwhile). Subscribing from an effect and reading the global in `Update` costs one list entry per subscribed component and avoids a `core` API; the catch-up and the read-at-apply rule make a missed or reordered notification impossible. A Provider is smaller than a telatest option (it also works in apps) and cannot leak between parallel tests, which a global setter cannot guarantee. Strings for locales keep x/text out of the public API. Generating dates from CLDR (rather than hand-writing patterns) keeps 113 locales exact and updatable; vendoring a trimmed subtree keeps the repository at 0.5 MB instead of about 2 MB. Verified: plural categories for en, es, fr, ru, ar, ja, pl and ordinals; numbers (`1.234,5`, `1 234,5`, `12,34,567`, Arabic-Indic digits); short/medium/long/full dates in en, es, ja, ar and seven more locales; telatest checks that `SetLocale` builds only the components that call `UseT` or `UseLocale` (one build each), from handlers and goroutines, and that Providers isolate subtrees
