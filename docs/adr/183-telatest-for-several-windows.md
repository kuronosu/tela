# ADR-183: `telatest` for several windows

- **Date:** 2026-10-27
- **Status:** Accepted

## Decision

(Phase 12, step C; amends ADR-059, ADR-086, ADR-174 and ADR-180, which said telatest sees the main window only; Playwright's pages and popups, with Tela names.) **One `*App` per window.** `Mount` returns the `App` of the main window; `Windows()` (open windows in order of opening, main first), `Window(title)`, `WindowAt(i)`, `LastWindow()`, `MainWindow()` and `WaitForWindow(f)` (Playwright's `waitForEvent('popup')`: the window `f` opened) return an `*App` scoped to a window (`win` and `tree` differ; the clock, settling, dev messages and the end of the app are shared), always the same value for a window. Every query, action, expectation, golden and `PixelAt` works on it unchanged. Selecting waits for the window to open; settling covers every window's tree (not hidden or minimized ones, which the fake window manager gives no frames), and `Press`, `Type` and pointer presses activate their window first, as a user does. **Window API on `*App`:** `Title`, `WindowState` (`tela.WindowState`), `WindowSize`, `Placement`, `Modal`, `Parent`, `Blocks`, `BlockedBy`, `Closed`; `ExpectTitle`, `ExpectWindowState(Maximized|Fullscreen|Minimized|Hidden|Active|ClientDecorations(bool))`, `ExpectClosed`, `ExpectWindowCount`, `ExpectNoWindow`; `RequestClose` (the close button), `Minimize`, `Maximize`, `Unmaximize`, `SetFullscreen`, `Restore`, `Move`, `BringToFront` (done through the fake WM, not the app); `HitRegions`, `HitAt`, `CaptionDrags`, `WindowMenus` for custom title bars (a click on a caption region is the OS's press). **Quit:** `HasQuit`, `ExpectQuit`, `ExpectRunning`; once `tela.Quit` ran or the main window closed without `OnClose`, telatest ends the app as `Run` does (windows unmounted, cleanups run) and further use fails with the reason. **`MountApp`** applies the OS-window fields of `tela.App` (`Title`, `AppID`, size limits, `FixedSize`, `Frameless`, `AlwaysOnTop`, `Hidden`, `Icon`, `Placement`, `OnClose`) through new options (`Title`, `MinSize`, `MaxSize`, `FixedSize`, `Frameless`, `AlwaysOnTop`, `StartHidden`, `Icon`, `Placement`, `OnClose`, `Screen`); `FromApp` does not (`tela snapshot` and `tela mcp` want the screen visible). `Host.NeedsFrame` ignores windows that get no frames.

## Rationale

A window-scoped `*App` reuses the whole API with no duplicate methods; Playwright's page model is what users and LLMs know. Window changes go through the fake WM so tests see what the OS would do. `tela mcp` needs nothing now; a `windows` and `select window` tool can follow.
