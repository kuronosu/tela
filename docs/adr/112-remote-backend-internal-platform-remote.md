# ADR-112: Remote backend, `internal/platform/remote`

- **Date:** 2026-10-22
- **Status:** Accepted

## Decision

Remote backend, `internal/platform/remote` (phase 9, T1; implements G1a/G2a of ADR-111; amends §15's backend table). **Protocol** ("remote app" protocol, version 1): length-prefixed frames with a hand-written little-endian encoding over an AF_UNIX stream socket (`$XDG_RUNTIME_DIR` or the temporary directory, Windows included), opened by a handshake (hello: magic, version, pid, tag; welcome: host clock, system settings, backend name; or a rejection with its reason). Each side writes from a goroutine fed by a queue, so the host's UI thread never blocks on a child. Window operations carry window IDs (1, 2… in creation order), and a swap maps the new child's window N onto real window N: title, cursor and text input state are applied; size, minimum size and fixed flag stay those of the real window (`platform.Window` cannot change them). Every event of the sealed set has an encoding: a test parses package `platform` for `isEvent` methods and fails on a type without one, and random round trips (`testing/quick`) fail on a field missing from one. `WakeEvent`, `Wake` and `Quit` are local to the child, whose loop is `internal/loop`'s with its windows unregistered (FrameEvents come from the host). **Clock:** the child's `Now` is the host backend's, with the offset measured at the handshake (midpoint of the round trip; both processes read the same monotonic clock). **Shared memory:** one segment per window and framebuffer size, created by the child: a memfd sealed against resizing on Linux and an unlinked temporary file on macOS, passed with SCM_RIGHTS; a named `Local\` file mapping on Windows (its AF_UNIX cannot pass handles), opened by name. The host checks the size before mapping. **Buffering:** two full-frame slots per segment. Present copies only the damage into a free slot and sends slot, generation, metrics and damage; the host's reader goroutine copies the same damage out into its retained frame, under the lock its UI thread presents from, and releases the slot. So the child never writes a slot being read, the host never shows a torn frame, and a slot needs valid pixels only inside its own damage (no buffer-age repair as in the Wayland swapchain); Present waits only when both slots are busy (an error after 5 s). A size change makes a new generation; old segments, and a closed window's unacknowledged one, are unmapped once the host acknowledges a newer generation (Windows needs the name alive until the host opens it). **Host:** `remote.Host` is the `platform.Handler` of any backend; its goroutines (accept, reader and writer per child) hand work to the UI thread with `Wake`, and `Post` runs supervisor code there. Children are active (shown, receive input), pending (receive Configure with the real metrics, FrameEvents on request, focus and settings; render offscreen, their frames kept) or detached; the first child to connect while none is active and input is not frozen becomes active. `Freeze` queues input (pointer, scroll, key, IME, IME session, focus, close requests); `Promote` presents the pending child's latest frame in full, applies its window state, restarts the IME session, sends a pointer enter where the pointer is, replays the queue in order and detaches the old child (the caller stops it); `Unfreeze` replays to the active child. Each child window has a view of its window (focus, held keys, IME session) that every event passes through, so a child that missed events while pending still gets a contract-valid stream (no release without its press). **Forced scale** (`--scale`): ConfigureEvents carry the forced scale with the real logical size; frames are resampled to the real physical size with nearest-neighbor sampling and their damage mapped exactly; a scale change of the real window re-presents without a new child frame. **Overlay hook:** `SetOverlay(func(w, fb))` draws over each composed frame right before Present (every present is then full); a detached or disconnected child's last frame stays on its window, and `Frame` returns a copy of it. **Control channel:** requests (kind, payload, one reply or error) and notifications in both directions, handlers on each side's UI thread; this package gives kinds no meaning. **Measured** (Core Ultra 5 125H, capped to 4 CPUs): a full-frame Present (child copy and host copy, until the slot is released) costs 2.3 ms at 1920×1080 and 6.3 ms at 2880×1800, 3.2 ms and 7.9 ms until the real (headless) window presented it; an input event takes 51 µs from the host window to the child's handler; a 2× nearest-neighbor upscale of 1440×900 takes 5.4 ms

## Rationale

Copying out on the host's reader goroutine keeps the slots independent of how busy the host's UI thread is, so Present costs two memcpys of the damage and almost never waits; damage-only slots make two slots enough without the swapchain's repair logic. Descriptor passing needs no names or cleanup on Unix; Windows has no equivalent over AF_UNIX, and DuplicateHandle would need a handle to the host process. The per-child view is what lets a pending child that saw no input join mid-stream under the keyboard and IME contracts, and checking the encoding against the package's source keeps the event list from going stale
