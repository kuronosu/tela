# ADR-091: Ergonomics

- **Date:** 2026-10-21
- **Status:** Accepted

## Decision

Ergonomics (phase 7, T2a; the API shapes are the owner's; amends §7, §12, §19, ADR-051, ADR-053, ADR-060, ADR-069, ADR-076, ADR-080 and ADR-088). **Handlers.** Every `h.On…` handler is generic over `F func() | func(E)` (`E` its event type; mouse, pointer, drag, wheel, scroll, key, focus, change, beforeinput, composition, select, submit, long press): `h.onEvent[E, F]` turns a `func()` into `func(E)` and hands core the same `func(E)`, so the event tables, forwarders and `UseCallback` are unchanged; a typed nil panics naming both shapes, and `OnClick(nil)` no longer compiles (F cannot be inferred). The union has no `~`: a named func type is not accepted. **Class** takes `parts ...string`, joined with one space, blank parts skipped; core still takes one string, so one part is passed as given. **Keys.** `tela.C`, `CP` and `Memo` take a last `key ...Prop`, the Prop `h.Key` returns (tela cannot import h, and a dedicated type would break `If(c, Key(k))` and `[]tela.Prop`): `core.keyedComponent` applies it to the new node, skips the zero Prop, and panics for any other prop ("takes only Key as its last argument"); with several Keys the last wins; `h.MapKeyed[T, K comparable](items, key, render func(T) tela.Component)` is `core.List` of `tela.WithKey(render(it), key(it))`; `h.Nodes([]tela.Node)` is `core.NodeList`, a fragment of a copy of the slice that, unlike `List`, is not dynamic, so dev mode does not ask for keys. **Bind.** `h.Bind[S tela.Setter[string] | func(string)]` (`core.Bind` and `core.BindFunc` share `bindProp`); `BindValue` stays the `*Value` form. **Toggle and Values.** `tela.Toggle(set Setter[bool]) func()` calls `set.Update` (two events in one frame chain; a zero Setter panics), `tela.MapValue[T, U](v *Value[T], f) func() U` and `h.Scale(v *Value[float32], k) func() float32` read `v.Get()` when the closure runs, so they track in the phase of the Fn prop that holds them (`WidthFn`, `HeightFn`, `OpacityFn`, `BgFn`, `TextColorFn`; `TranslateFn` returns two values and has no helper). **Style props.** `tela.StyleProp` is `core.StyleProp`, a struct of `[]style.Op` (it was an alias of `style.Op`, which cannot implement `Child` because style sits below core), with `Build` returning the node of `Style(ops...)`: `propOf` treats it as a Prop (a zero one is the zero Prop, so `If(false, tela.Width(1))` works even in a Fragment), `h.Style(props ...tela.StyleProp)` flattens it with `core.StyleOpsOf`, and `CheckIf` accepts it; the typed constructors wrap one op, `tela.Box(x, y, w, h)` is Left, Top, Width and Height and `tela.WH(w, h)` Width and Height (`tela.Size` is the animated size type, so the second pack is `WH`: decided without the owner). A StyleProp is not comparable (it holds a slice; `style.Op` already held funcs). **Animation.** `type Easing string` with `EaseLinear`, `EaseIn`, `EaseOut`, `EaseInOut` (CSS's keywords: Tailwind's ease-out is `CubicBezier(0, 0, 0.2, 1)`, not `EaseOut`; no constant for the default "ease"), `CubicBezier(x1, y1, x2, y2 float32) Easing` (shortest float formatting, validated by `Ease` in dev mode like any string) and `Ease(e Easing)`: literals still compile, a `string` variable needs `tela.Easing(s)`. `tela.UsePresenceTween(opts...) *Value[float32]` (`core.UsePresenceTween`) is `UsePresence` plus a `UseTween` of 1 (0 while exiting) with `Initial(0)` and an `OnDone` that runs the caller's `OnDone` options and then `done`; spring options (`Stiffness`, `Damping`, `Bounce`, `Velocity`, `Spring`) make it a `UseSpring`; the options must not change between builds, since the hook kind is chosen by them. **VirtualList.** `h.ItemKey[K comparable](func(i int) K)` keys the item wrappers by the key instead of the index (the wrapper node's key; `vl.nodes` is already cleared when the parent builds; measured sizes stay per index, so moved items are measured again when laid out), `h.ItemHeight(px)` (1 px or more) sets every item's height: the estimate is `fixedEstimate(px)` (estimateSize may be nil), the wrapper gets that height, `measure` skips sizes, and a change of the height resets the sizes; roles: the list is `list` and an item `listitem` while the list's role is `list` (`Tree.implicitRole`; `Role` on the list replaces it and its items then have none), the content box has none. This changes the aria snapshot of every VirtualList, so rows must not add `Role("listitem")` (examples/virtuallist did and was changed). Rendering is unchanged: every golden is bit-identical.

## Rationale

The owner's shapes, with three forced deviations: the key is a plain `Prop` (above), `StyleProp` is a struct (above) and the second pack is `WH`. The generic handler costs one wrapper closure per `func()` handler and a type switch per prop; the union stays closed so `Div(OnClick(f))` with a callback of another shape is a compile error, not a runtime one. `UsePresenceTween` is the copy in `motion` and `dashboard` minus 6 lines, and keeps their behavior (the exit tween's `OnDone` calls `done`, which does nothing while present)
