# ADR-111: Dev loop, `tela dev`

- **Date:** 2026-10-22
- **Status:** Accepted

## Decision

Dev loop, `tela dev` (phase 9; options G1–G9 decided by the owner; amends §5 and §17). **Model.** Go cannot swap code in a running process without cgo or an interpreter (ADR-001), so the dev loop rebuilds and restarts the app and makes the restart invisible. `tela dev [pkg]` is a supervisor that never restarts: it owns the real window (`internal/platform/auto`) and runs the app as a child process whose backend is `internal/platform/remote`, a `platform.Backend` over IPC (G1a). Frames travel through shared memory (memfd on Linux, a file mapping on Windows) and events, damage, clock, clipboard, IME, cursor, title, size and settings through an AF_UNIX socket (G2a; Go supports AF_UNIX on Windows 10 and later). The protocol carries window IDs and is a general "remote app" protocol that `tela mcp` and DevTools may reuse later, but only what `tela dev` needs is implemented. **Swap.** On a save (any non-test `.go` file of the main module, `go.mod`/`go.sum`, embedded files, `os.DirFS` roots registered with `tela.Assets`; debounced 100 ms; G6a) the supervisor builds with `-tags teladev` into a temporary binary while the running child stays interactive, cancelling the build on a newer save; after a successful build it asks child N for its state, queues further input, starts child N+1 with that state, shows N+1's first frame in place of N's and stops N. **State (G3a+d).** A hook slot's identity is the path of component Elements from the root (component type plus key, or position), the hook's index and kind and the value's type; serializable `UseState`, `UseReducer`, `UseValue` and `UseRef` slots (encoding/gob) are seeded into the new build, a component whose hook list changed resets (React Fast Refresh's rule), and dev mode warns once per slot that cannot be kept. Engine state is kept too: uncontrolled field text, selection and undo history, scroll offsets, focus, the runtime color scheme and theme; exiting `Presence` children are dropped (owner, 2026-10-22). Animations restart from rest and effects run again on mount. State outside the tree uses `App.DevState{Save, Restore}` (G4a). **Errors (G5).** A build error or a panic is shown on the terminal and as an overlay drawn by the supervisor over the last good frame (a headless Tela tree composited over it); the window never closes and the next good build clears it. **CLI (G8a).** `--size`, `--scale` (the child renders at that scale; the supervisor resamples to the window), `--dark`, `--preview NAME`, `--no-state`; terminal keys `r` reload, `R` reload without state, `q` quit. **Platforms (G9a):** Linux (Wayland, X11) and Windows; macOS with its backend (phase 14). **Target (G7):** save to new frame within 1.5 s on `examples/dashboard`, stretch under 1 s. Not done: goldens on save, undo of a reload. **Release builds are unchanged (owner's condition).** Dev-loop code compiles only under the `teladev` build tag: its packages are imported only by `//go:build teladev` files, and the hook points in `core` are guarded by a constant that is false without the tag (`devstate_off.go`), so the compiler removes them. A test builds an app without the tag and checks that `go list -deps` has no dev-loop package and `go tool nm` no dev-loop symbol (nor `encoding/gob`); at phase close the release binary of `examples/dashboard` is compared with `v0.8.2`, differing only by the type information of `App.DevState`. Tag-only tests run with `go test -tags teladev`. Apps assign `App.DevState` from a `//go:build teladev` file so their own save/restore code is not linked into release builds either

## Rationale

The owner wants an imperceptible reload loop before `kit`. Only a process that never restarts can keep a Wayland surface or a Win32 window; shared memory avoids copying every frame through the kernel twice; identity by component path plus hook signature is React Fast Refresh's rule, which users know; a build tag, rather than linker dead-code elimination alone, makes "release builds are unchanged" checkable and keeps gob, the IPC code and the watcher out of every shipped binary
