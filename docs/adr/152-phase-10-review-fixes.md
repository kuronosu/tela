# ADR-152: Phase-10 review fixes

- **Date:** 2026-10-25
- **Status:** Accepted

## Decision

Phase-10 review fixes (`/code-review high` of the kit, `aria` and `i18n` work; every fix has a test that failed before it). **1. `Toaster{Expand: true}`** paused every timer for good: the timers are paused only while the pointer is over the stack, and `Expand` only fans the stack out, as in sonner (`TestToastExpandDoesNotPauseTheTimers`). **2. `ToastReplace(id)` of an id no toast has** reserves the id (`next = max(next, id)`; ids are allocated by `next++`, so the next automatic one is `id+1`), so later automatic ids cannot collide with it (`TestToastReplaceOfAnUnknownIDReservesIt`). **3. `Select` group and separator keys** are the index of the item where the group or the separator begins, not the group name, so a name (or the ungrouped run) that comes back after another group no longer repeats a key, which warned in dev mode and remounted the rows (`TestSelectRepeatedGroupsHaveDistinctKeys`, which collects the dev warnings through a `testing.TB` wrapper). **4. A toast's height** is measured from its own root, not the body plus a constant of 34 px: while the toast has no height class yet (`toastItem.unforced`, the first frame; a height forced by the stack would be measured back) the root's size minus the body's is kept as the item's chrome, and a changed body is that much taller; a recipe that changes `ToastStyle.Item`'s padding or border now gives a taller or shorter toast (`TestToastHeightFollowsTheItemRecipe`: `p-8` adds 32 px, `border-4` 6 px). A toast not measured yet is not given the front toast's height while it is behind it, for that one frame. **5. `Slider.DefaultValue` is a `*float64`** (the shape of `RadioGroup.DefaultValue`), because 0 was read as unset and a slider whose range includes 0 started at `Min`; callers write `DefaultValue: new(50.0)`; the tests, the gallery and the wiki follow (`TestSliderDefaultValueZero`). **6. Copyright notices:** every kit file that ports shadcn/ui's class strings and markup (MIT, Copyright (c) 2023 shadcn), follows sonner (MIT, Copyright (c) 2023 Emil Kowalski) or embeds Lucide icons (ISC, Copyright (c) 2026 Lucide Icons and Contributors; Feather's icons MIT, Copyright (c) 2013-present Cole Bemis) starts with a notice in the style of the `aria` ports (`kit.go` for the theme CSS; `choice.go` for its two icons); `THIRD_PARTY.md` lists `table.go` and `kit.go`, which it had left out. The generated `icons_gen.go` of every example already carried Lucide's license (`tela icons gen` writes it). **7. `aria.ParseHexColor` and `FormatHexColor`** convert through `internal/gfx` (`ParseHex`, `Color.String`) and keep the lenient input (trim, optional `#`) and their own error messages, which the tests and the example pin; the duplicate decoder is gone (`hexDigit` stays, for the validation that words the errors and for the color field's typing filter). **8. `kit`'s `devMode()`** provoked an `h.Role` panic and recovered it on every build of a table, a popover or a menu (164 allocations a call); it is `core.DevNow()` now, a lookup, and it is the only import of `internal/core` in `kit` (`TestDevModeCostsNoPanic`). **9. `i18n`: `cccccc`** (CLDR's short width) prints the short stand-alone name, as `WeekdayName(NameShort)` does ("Mo", not "Mon"); `EEEEEE` and `eeeeee` keep the abbreviated name, because the data has the short names only stand-alone (`TestStandAlonePatternLetters`). **10. `ColorInput{Disabled: true}`** passes `Disabled` to its `Popover` (ADR-145) instead of drawing its trigger without one: the trigger is the popover's, inert and closed (`TestColorInputDisabled`). **Goldens:** none changed

## Rationale

**Deviation from the review on 8:** caching the probe once per process, as suggested, would give a tree built with `telatest.NoDev` the mode of the first tree (`TestUndefinedVariantAndSizePanicWithTheClosest` renders the same component in both modes), and ADR-093's per-tree mode is reachable from `internal/core`, which `aria` and `i18n` already use; reading it there is exact and free, at the price of one `internal` import in a package that ADR-129 wanted to import only public ones (a copied-source distribution would swap that function, or the owner could expose a public `tela.DevMode()`, left to the owner). The toast chrome is measured instead of constant so that the recipe is the whole truth about the look, as K17 says; the pointer for `DefaultValue` is a breaking change of a field one phase old, taken before v0.10.0
