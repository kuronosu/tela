# ADR-195: Nine examples

- **Date:** 2026-10-30
- **Status:** Accepted

## Decision

`examples/` keeps nine full screens, each with a clear role and most with a later phase that grows it: `hello` (the README's hero, kept minimal), `counter` (ARCHITECTURE §1, redesigned in stone), `kit` (the gallery; gains an Introduction page and absorbs `i18n` as a language and direction switch), `settings` (merged with `llms/settings`; the `llms.txt` example, regenerated by an LLM from a rich prompt in at most three iterations), `notes` (phases 13, 17, 19; full redesign), `dashboard` (phase 16; cleaner glass redesign, absorbs `board` as a board view and part of `aria` as components built on `aria` hooks), `login` (absorbs `signup`; the phase-15 screen), `player` (phase 20) and `chat`.

`motion`, `layout`, `virtuallist`, `shapes` and `text` become package tests and godoc `Example`s; `pricing` goes. `native`'s three looks move to a nested module `looks/` (one package per look with a `tela.Theme` and a `kit.Style`, plus `Detect`), which needs its own ADR before it is created; the explorer goes.

## Rationale

21 examples grew one per phase or feature: some duplicate others, `text` uses `internal/` packages, and phase 14 must verify every example on macOS. Feature demos belong in godoc, which v1.0 requires anyway.

## What it changes

Before an example is deleted, its unique tests move to the package they test. The phase-15 criterion names `login`. Removing `text` drops the `Scene` contract of `tela snapshot` (a CLI change). Tracked in ROADMAP, "Examples".
