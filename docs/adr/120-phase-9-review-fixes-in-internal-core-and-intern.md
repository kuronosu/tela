# ADR-120: Phase-9 review fixes in `internal/core` and `internal/text/edit`

- **Date:** 2026-10-22
- **Status:** Accepted

## Decision

Phase-9 review fixes in `internal/core` and `internal/text/edit` (amends ADR-113, ADR-114 and ADR-118). **Focus fix-up** (ADR-114): leaving a focused element without a computed style alone is dev-only. `fixFocus` asks `devFocusWaits`, a teladev hook point that `devstate_off.go` stubs to false, and has its shape from before ADR-114, so its release code is instruction-identical to that one (`-trimpath` builds of `examples/dashboard`) and `fixFocus` leaves ADR-114's list of release symbols that differ. Only `devFocus` focuses an element without a computed style: every release focus path (`ElementRef.Focus`, Tab, a press, a Label, AutoFocus, the focus scopes and the focus manager) requires one through `focusable` or the tab walk, and a box never loses it; `TestFixFocusUnstyledOff` pins the release behaviour. **Caret reveals** (ADR-118): a reveal also waits for the next layout when a passive effect asks for it (`FlushEffects` holds reveals while the effects run, inside or outside a frame) or the posted functions and scroll handlers at the start of a frame do (the hold now begins with the frame), since the updates they queue apply in the next build; a queued reveal requests the repaint of the frame that runs it. Before, `ElementRef.Focus` in a `UseEffect` that also narrows the field, in either order, revealed the caret with the old width. **Snapshots** (ADR-113): every node but the root must have an identity in range; an empty ID exempted any node, so a damaged snapshot could panic. **Discarded first builds** (ADR-113): the Values read only by a first build discarded for a changed signature are not subscriptions of the component (`build` passes its tracking mark to `devFirstBuild`). **Text fields** (ADR-113): `RestoreDevState` keeps the saved selection only when the cleaned value is the saved one, as it does the history (a Textarea's text restored into an Input loses its line breaks, and the saved offsets selected other text); otherwise the caret goes to the end, as `SetText` puts it

## Rationale

Review findings of phase 9. The owner's condition (ADR-111) is that release builds do not change: a test that only tela dev's restore needs belongs behind the tag, and an identical `fixFocus` makes that checkable. A reveal needs a layout that includes the updates of the code asking for it; effects and a frame's preamble queue updates the layout has not seen, and holding their reveals costs nothing visible, since the frame that applies the updates paints after revealing. The other fixes restore what ADR-113 promised; every golden is unchanged
