# Recipe: i18n

Questions: how to translate an app and switch the language at run time; plurals and ICU messages; formatting numbers, currency, percent, compact numbers, signs and rounding, dates and lists for the user's locale; right-to-left; how Tela's own texts (title bar buttons, message boxes, toasts) are translated; how to test a locale.

Package `github.com/kuronosu/tela/i18n`. Messages live in one JSON file per locale, named after it (`locales/en.json`, `locales/es.json`), written in ICU MessageFormat: `{"hello": "Hello, {name}!", "files": "{count, plural, =0 {No files} one {# file} other {# files}}"}`. Embed them (`//go:embed locales/*.json` on a `var locales embed.FS`) and load them once with `i18n.Load(locales, "locales/*.json")` (`Replace` for catalogs that change while the program runs). A key is looked up in the locale's catalog, then its parents' (`es-MX`, `es`) and the fallback's; a key found nowhere is returned as is and reported once in dev mode. The current locale is the system's when a catalog covers its language, else the fallback (`en`).

**Components.** `t := i18n.UseT()` is a hook that rebuilds the component when the locale changes: `t("files", "count", n)` takes name/value pairs; handlers and goroutines use `i18n.T`. `i18n.SetLocale("es")` rebuilds the components that read the locale, and only those. `i18n.UseLocale()` returns the tag, `i18n.UseFormatter()` a `Formatter` for the component's locale, `i18n.For(tag)` the one of another locale. `i18n.Dir(tag)` says `RTL` or `LTR`; `h.Dir("rtl")` lays a subtree out right to left (`tela.UseDirection()` reads the direction in code). A test fixes one tree's locale with `i18n.Provider("es", children...)`, without touching the process's.

**Numbers, dates, lists** (`Formatter` methods, or `i18n.FormatNumber`, `FormatDate`, `FormatTime`, `FormatDateTime`, `FormatList` for the current locale). Numbers are written as `Intl.NumberFormat` does, from CLDR 48, with its options and defaults, except that a tie rounds to the even digit (`RoundingMode(i18n.RoundHalfExpand)` is Intl's):

- `i18n.Percent()`; `i18n.Currency("EUR")` with `CurrencyDisplay` (`CurrencySymbol`, `CurrencyNarrowSymbol`, `CurrencyCode`, `CurrencyName`) and `CurrencySign(i18n.CurrencySignAccounting)` (parentheses for negatives where the locale has them); only currencies in use have symbols and names, others show their code.
- `SignDisplay`: `SignAuto` (default), `SignAlways` ("+5"), `SignExceptZero`, `SignNegative`, `SignNever`.
- `Notation`: `NotationStandard`, `NotationScientific`, `NotationEngineering`, `NotationCompact` ("1.2M", "1,2 Mio.", "123万") with `CompactDisplay(i18n.CompactLong)` for words.
- `MinFractionDigits`, `MaxFractionDigits`, `NoGrouping`, and `RoundingMode` with Intl's nine modes (`RoundHalfEven` the default, `RoundHalfExpand`, `RoundCeil`, `RoundFloor`, `RoundExpand`, `RoundTrunc`, `RoundHalfCeil`, `RoundHalfFloor`, `RoundHalfTrunc`).
- Digits follow the locale's default numbering system (`ar-EG` writes Arabic-Indic digits, bare `ar` Latin ones); a tag's `-u-nu-` wins (`en-u-nu-thai`).
- In a message: `{n, number}`, `{n, number, percent}`, `{n, number, currency}` (the locale's currency), or an ICU number skeleton after `::` (`{n, number, ::currency/EUR}`, `::compact-short`, `::scientific`, `::sign-always`, `::.00`, `::percent`, `::rounding-mode-ceiling`, `::group-off`); an unsupported stem fails when the catalog loads, not at run time. Also `{d, date, medium}`, `{d, time, short}`, `plural`, `selectordinal`, `select`, `#` and nesting.
- Dates are Gregorian, in the `time.Time`'s own zone: `f.Date(t, i18n.Long)` (`Short`, `Medium`, `Long`, `Full`), `f.MonthName`, `f.WeekdayName`, `f.FirstDayOfWeek()`.

**Tela's own texts** (the fallback title bar's buttons, message box buttons, kit's toast viewport and its close button, the standard menu items, the macOS save panel) have fixed IDs with English defaults (`tela.Labels()` lists them: `tela.titlebar.close`, `tela.messagebox.ok`, `tela.toast.close`, `tela.menu.quit`...). Tela ships no translations: importing `i18n` makes the catalogs their source, so a message whose key is the ID translates it, in the same JSON (`{"tela": {"toast": {"close": "Cerrar aviso"}}}`); labels the catalogs lack stay English. `tela.Label(id, "name", "Notes")` reads one (a handler), `tela.UseLabels()` is the hook for a component, `i18n.For("es").Label(id)` gives another locale's, and `kit.Toaster{AriaLabel, CloseLabel}` overrides two of them. Native message box buttons on Windows and macOS menus follow the language too.

```go
package app

import (
	"testing/fstest"

	"github.com/kuronosu/tela"
	. "github.com/kuronosu/tela/h"
	"github.com/kuronosu/tela/i18n"
	"github.com/kuronosu/tela/kit"
)

// locales stands for the embedded catalogs of a real app.
var locales = fstest.MapFS{
	"locales/en.json": {Data: []byte(`{"files": "{count, plural, =0 {No files} one {# file} other {# files}}", "price": "Total: {total, number, ::currency/EUR}", "tela": {"toast": {"close": "Close toast"}}}`)},
	"locales/es.json": {Data: []byte(`{"files": "{count, plural, =0 {Sin archivos} one {# archivo} other {# archivos}}", "price": "Total: {total, number, ::currency/EUR}", "tela": {"toast": {"close": "Cerrar aviso"}}}`)},
}

func init() {
	if err := i18n.Load(locales, "locales/*.json"); err != nil {
		panic(err)
	}
}

// Summary reads the locale with hooks, so SetLocale rebuilds it.
func Summary(n int, total, growth float64) tela.Node { return tela.C(func() tela.Node {
	t := i18n.UseT()
	f := i18n.UseFormatter()
	return Div(Class("flex flex-col gap-1 text-sm"),
		Text(t("files", "count", n)),
		Text(t("price", "total", total)),
		Textf("%s this week", f.Number(growth, i18n.Percent(), i18n.SignDisplay(i18n.SignAlways))), // "+8%"
		Text(f.Number(1234567, i18n.Notation(i18n.NotationCompact))),                               // "1.2M", "1,2 M" (es)
		Text(f.Number(-1234.5, i18n.Currency("USD"), i18n.CurrencySign(i18n.CurrencySignAccounting))),
		Text(f.List([]string{"tea", "coffee", "milk"})), // "tea, coffee, and milk"
		kit.Button{Children: Text("Español"), OnClick: func() { i18n.SetLocale("es") }})
}) }
```

```go
package app

import (
	"testing"

	"github.com/kuronosu/tela"
	"github.com/kuronosu/tela/i18n"
	"github.com/kuronosu/tela/telatest"
)

func TestSummaryInSpanish(t *testing.T) {
	app := telatest.MountFunc(t, func() tela.Node {
		return i18n.Provider("es", Summary(3, 12.5, 0.08)) // this tree only, not the process's locale
	})
	app.ExpectText("3 archivos")
}
```

`tela verify` also runs a screen in another language (the first other locale of a package that links `i18n`; `--lang` picks one) and right to left, so text that does not fit a longer translation shows up as a finding (recipe accessibility).
