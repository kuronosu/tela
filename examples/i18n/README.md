# i18n

An order summary in English, Spanish and Arabic, built only on package `kit` in its default (shadcn) style: a language `kit.Select` that changes the language while the app runs, and a `kit.DatePicker` whose calendar shows the locale's month names, first day of the week and digits, all laid out right to left in Arabic.

What it shows:

- **Catalogs.** `locales/en.json`, `es.json` and `ar.json` hold ICU MessageFormat messages, embedded with `//go:embed` and loaded by `i18n.Load` in `init`: arguments (`Hello, {name}!`), plurals (Arabic has six categories: `zero one two few many other`), an English ordinal (`selectordinal`) and nested keys (`summary.discount`).
- **Formatting.** `i18n.UseFormatter` gives the locale's numbers (`1,234.50`, `1.234,50`, `١٬٢٣٤٫٥٠`), percentages, full dates, short times and lists (`apples, pears, and figs`, `manzanas, peras y higos`, `تفاح وكمثرى وتين`).
- **kit components, no hand-made controls.** The language switcher is a `kit.Select` (each option named in its own language; the trigger's accessible name is the current language followed by the catalog's "Language"); the cards are `kit.Card`; Remove, Add, Back and Checkout are `kit.Button`s with icons from a Lucide subset (`icons/`, generated by `tela icons gen`); the progress of the order is a `kit.Progress`; the summary rows are separated by `kit.Separator`; the delivery date is a `kit.Field` around a `kit.DatePicker`; the logo is a `kit.Avatar`.
- **Theme tokens.** `bg-background`, `text-muted-foreground` and the kit's recipes, and `kit.Theme()` in `var App`: there are no color pairs and no `dark:` classes, so the same screen is right in light and dark (`--dark`).
- **kit's English defaults come from the catalog.** `DatePicker.Placeholder` ("Pick a date"), `PreviousLabel` and `NextLabel` (the calendar's month buttons) are set with `t(...)`; the picker's own text and the calendar's month, weekday names, first weekday and digits follow the locale on their own (`i18n.UseFormatter` inside kit). Arabic's short weekday names do not fit a calendar cell, so the example sets `NarrowWeekdays` for it.
- **Runtime switching.** The Select calls `i18n.SetLocale`; the components that read the locale through hooks build again and nothing else does. The open calendar keeps its popover and the chosen date, and every text of it becomes the new language's.
- **Right to left.** The screen puts `Dir(f.Dir().String())` on its root, and the kit follows: the header, the card headers and the rows mirror, `kit.Progress` fills from the right (`rtl:translate-x-*`), the Select's list puts the check at the left end of the row, the DatePicker's popover opens from the right edge with the weekdays running right to left and the previous and next buttons swapped, the values (`ms-auto text-end`) go to the left and Checkout (`ms-auto`) goes to the left. The back arrow is `icons.ArrowRight` in Arabic (`kit.Button` has no class for its icon, so it is picked in Go). Arabic text uses the embedded Noto Sans Arabic.

## Run it

- In a window: `CGO_ENABLED=0 go run ./examples/i18n` (720x800). It starts in the system's language when it is English, Spanish or Arabic, else in English.
- Without a window: `CGO_ENABLED=0 go run ./cmd/tela snapshot --size 720x800 [--dark] [--preview ar|en|es] -o i18n.png ./examples/i18n`; the previews fix their locale with `i18n.Provider`, and the app's theme and root class come from `var App`.
- Its aria snapshot: `CGO_ENABLED=0 go run ./cmd/tela inspect --aria --preview ar ./examples/i18n` (`testdata/i18n_{en,es,ar}.aria.yml`, and `*_picker.aria.yml` with the calendar open).
- Tests: `CGO_ENABLED=0 go test ./examples/i18n`. They check the texts and formats of each language, Arabic's plural categories as the counter changes, switching language with the Select (by pointer and keyboard: Back, Checkout, the Select and the progress bar mirror and come back), the calendar of each language (month, weekday order and direction, month buttons, unavailable dates), choosing a date and seeing it in the summary, changing the language with the picker open and closed, and the goldens (`testdata/i18n_{en,es,ar}_x*.png`, `i18n_dark_*`, `i18n_picker_*` with the calendar open, `i18n_select_*` with the list open, `i18n_chosen_ar_x1.png`; regenerate with `TELA_UPDATE=1 CGO_ENABLED=0 go test ./examples/i18n`).
