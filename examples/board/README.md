# board

A small kanban board built only on package `kit`, in its default (shadcn) style: three columns (To do, In progress, Done) of cards with a title, a note, a tag, a comment count and an assignee. Cards can be dragged to another column, dropped between two cards, or reordered inside their column; each card also has a menu to move, edit or delete it.

What it shows:

- **kit components, no hand-made controls.** Each card is a `kit.Card` (the title, the note, the content row and an `Action` slot), its tag a `kit.Badge`, its assignee a `kit.Avatar`, the column counters `kit.Badge`s, Invite a `kit.Button`. The ellipsis at the card's corner is a `kit.DropdownMenu` whose trigger is an icon `kit.Button`, and the whole card is a `kit.ContextMenu` area (right click, or Shift+F10 from the card's button) with the same items: Move to each other column (a full column is disabled), Edit card and Delete card (`kit.Destructive`). Moving from the menu also works from the keyboard, which dragging does not.
- **Dialogs opened by state.** Edit opens a `kit.Dialog` with a `kit.Field` per input (`kit.Input` for the title, `kit.Textarea` for the note, `kit.Select` for the tag) and no trigger: the menu item sets the `Open` state of the card. Save is disabled while the title is empty. Delete asks with a `kit.AlertDialog` (Destructive). Moves, edits and deletes answer with a toast (`kit.Toaster` around the page, `kit.UseToast` in the card).
- **Icons.** The ellipsis, the comment bubble and the menu icons are a Lucide subset generated by `tela icons gen` (`icons/`).
- **Theme tokens.** The page uses `bg-background`, `bg-muted`, `bg-accent`, `text-muted-foreground`, `bg-primary` and the app has `kit.Theme()`, so there are no zinc pairs and no `dark:` classes; render it with `--dark`. The dots before the column names and the tags are decoration and keep palette colors, the same in both schemes.
- **Drag with `OnDragStart` / `OnDrag` / `OnDragEnd`.** The element around each card carries the drag handlers (a `kit.Card` takes one `Props` child, so its handlers cannot all go there). The dragged card follows the pointer with `tela.TranslateFn` reading a `tela.UseValue` (`DragState.Offset`, set from `e.OffsetX/OffsetY`), so a pointer move only repaints that card: `TestCardFollowsThePointer` checks 0 builds and 0 layouts over ten moves.
- **Lifting.** While dragged the card is `relative z-50 rotate-2 shadow-2xl ring-2` and `pointer-events-none`: it paints above the other columns, and the pointer reaches the column and the card under it.
- **Drop targets by pointer boundaries.** Columns and cards set `DragState.Over` from `OnMouseEnter` / `OnMouseLeave` while a drag is active; the column under the pointer gets a ring and the card it hovers gets an insertion line (an absolutely positioned bar, so nothing shifts under the pointer). On `OnDragEnd` the board moves the card to the last target (`Board.Move`); releasing outside any column puts it back.
- **Comparable state.** Columns are fixed-size arrays of card IDs and the cards' data is an array too, so the `Board` and the `Tasks` are comparable values in `UseState`, and the `tela.CP` lanes and cards skip their build when their props do not change.
- **`tela.Post` for ordering.** The drop runs inside `tela.Post`, which shares one queue with `Value` updates, so it sees the `Over` set by the last move even if no frame ran in between.

## Run it

- In a window: `CGO_ENABLED=0 go run ./examples/board` (1280x800).
- Without a window: `CGO_ENABLED=0 go run ./cmd/tela snapshot --size 1280x800 --scale 2 [--dark] -o board.png ./examples/board` (it reads `var App`, which has the theme and the root class).
- Its aria snapshot: `CGO_ENABLED=0 go run ./cmd/tela inspect --size 1280x800 ./examples/board` (`testdata/board.aria.yml`).
- Tests: `CGO_ENABLED=0 go test ./examples/board`. They cover the model (`Board.Move`), dragging to another column, between cards, inside a column and outside the board, the drop-target ring, a click not moving anything, the menu (moving by pointer and keyboard, a full column disabled, the context menu from the keyboard), the edit dialog (rename, tag, a required title, Cancel), the delete question, and the goldens (`testdata/board_x*.png`, `board_dark_x*.png`, `board_menu_x*.png`, `board_edit_x*.png`, `board_delete_x*.png`, `board_deleted_x*.png` with the toast; regenerate with `TELA_UPDATE=1 CGO_ENABLED=0 go test ./examples/board`).

A column holds at most eight cards; a window shorter than the columns scrolls like a page.
